# Windows 快捷方式

运行安装器后，本目录会保存以下本机快捷方式：

- `安装 Codex Dream Skin.lnk`
- `Codex Dream Skin - Restore.lnk`
- `切换 Codex Dream Skin 主题.lnk`
- `更换 Codex Dream Skin 图片.lnk`
- `恢复 Codex Dream Skin 默认图片.lnk`

“更换图片”会先选择图片，再选择“整窗背景”或“主页图片卡片”。没有 `image-mode.txt` 的旧安装默认保持主页卡片模式。

桌面只保留主启动入口 `Codex Dream Skin.lnk`。这些 `.lnk` 文件包含当前仓库的绝对路径，移动仓库后请重新运行安装器生成。
